# Source: INTP Detailed Profile (Chinese)

## Summary

This source is a comprehensive Chinese-language overview of the INTP personality type, referred to as the "Logician," "Thought Architect," or "Theory Explorer." It covers the INTP's cognitive function stack (Ti → Ne → Si → Fe), core temperament, strengths, weaknesses, relationship style, career fit, growth stages, psychological pitfalls, and practical self-improvement advice. The source is **not part of the Mediator Guide to Careers** and does not address the INFP type.

> ⚠️ **Relevance note:** This source is off-domain for this wiki. The wiki tracks career guidance for the INFP (Mediator) type. INTP is a distinct personality type. Content here is archived for reference only and has not been integrated into INFP-focused pages.

## Key claims

- INTP's core drive is to understand the underlying structure, principles, and logic of things, and to resist unverified conclusions.
- Cognitive stack: Ti (dominant) → Ne (auxiliary) → Si (tertiary) → Fe (inferior).
- Key strengths: abstract reasoning, independent thinking, detecting logical inconsistencies, patience with complex concepts, creating new frameworks.
- Key weaknesses: action delay (analysis paralysis), difficulty finishing projects, intolerance of real-world compromise, communication leaps, delayed emotional processing.
- Growth path: move from "think it through completely" to "design experiments"; externalize mental systems into documents/tools; develop Fe (emotional expression); accept messy reality as part of the model.
- Mature INTP: "calm rationality + gentle humanity + deep insight."
