# Professional Volunteerism (Career Field)

## Description
Full-time volunteerism allows Mediators to pursue conscience-driven work with profound personal satisfaction. It may require supporting income initially; any skill set can be applied to worthy causes, locally or abroad. Volunteer efforts can be individual or group-based, from tutoring to skilled trades.
